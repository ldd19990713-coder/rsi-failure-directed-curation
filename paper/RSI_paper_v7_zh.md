## 摘要

递归自我改进（RSI）研究关心：闭环更新何时能产生可验证增益，以及失效边界何在。科学研究与日常生活中有一常青直觉：从失败中吸取教训，在某种程度上比从成功中获取经验更重要——因为错误更能标出仍须修正的假设空间。我们将该直觉置于 RSI 议程中，落实为有界、数据中心的自精炼：优先修复模型做错之处，而非宣称开放式持续 RSI。少样本反应产物预测（精确 SMILES）是严苛试验田：监督稀缺，协议漂移与评测污染易制造虚假增益。在泄露受控划分（训练 46 / 评测 97）上，我们检验失败驱动数据策展（由模型错误生成增广）是否优于等预算随机增广、递归调度/朴素扩容是否有效、域内增益能否迁移到反应键不相交的 hold-out。冻结 Qwen2.5-7B + LoRA（bf16），N=5：A_fail 峰值 77.73%±2.79%，A_rand 11.13%±0.46%（Δ = +66.60pp）。硬回滚锁死早期峰值并损害性能；并入分布偏移样本诱发早峰后遗忘；局部 LR 调整未过稳化门禁。在与 train∪eval 反应键零重叠的 hold-out（n=31；18 类标签，其中 14 类名在训练中出现过但实例不同）上，基座与已训 LoRA 均为 0%。污染外集抬高的虚假泛化数字已撤回。结论：失败驱动策展可带来大幅、可复现的域内增益，但跨划分泛化未观测到——从而澄清数据中心自精炼的条件与边界，而非验证开放 RSI 或通用化学推理。

**关键词：** 递归自我改进，数据中心 AI，失败驱动策展，少样本学习，化学反应预测，评测诚信

## 1\. 引言

### 1.1 从 RSI 到有界自精炼：三层问题栈

本文置于 **递归自我改进（RSI）** 研究议程之下：迭代更新何时能产生**可审计、跨轮可验证**的性能改进，以及如何控制灾难性回撤与过拟合。我们将「开放/持续 RSI」保留为**长期评价地平线**，而非本阶段结论；采用**三层问题栈**，由领域级 RSI 问题逐步收窄到可证伪实验。

**第一层 · 大方向（Why）。** 在**有界**设定下，递归微调如何（以及能否）产生可验证的跨轮改进，并有效控制灾难性遗忘与过拟合？澄清通向更强 RSI 叙事的**条件、边界与不可行区域**，是任何「持续自我改进」主张的前提。

**第二层 · 具体方向（Where / What）。** 将第一层收窄到**数据中心**闭环，场景为**少样本化学反应产物预测**（精确 SMILES）：（i）**失败驱动增广**作为数据策略（故障 → 数据修复）；（ii）**多轮权重更新**（LoRA 微调）作为执行层。这一选择是刻意的：无论在科研还是日常解题中，**败中取法往往比重复成功更关键**——成功多半确认已知有效路径，失败则标出当前「世界模型」尚未覆盖的边界。因此我们把模型错误当作主要课程信号，而非用随机加量冲淡。目标是弄清该失败中心闭环相对恰当对照的**因果贡献**，以及遗忘、过拟合与薄弱评估协议导致的失效模式。本阶段**不研究**元层「改进如何改进」。

**第三层 · 实验聚焦（How）。** 在**无泄露、固定划分**下，以精确 SMILES 的峰值/末轮/回撤为主指标，冻结配方，预注册对照：失败定向 vs 随机增广；递归调度/扩容干预 vs 默认；域内增益 vs 反应键不相交 hold-out。唯有在此纪律下，才承认「改进」主张。

**漏斗关系。** 第一层说明闭环增益为何必须有界且可审计；第二层选定要检验的机制（化学场景中的失败驱动数据修复）；第三层导出下文 RQ。域内正效应部分回答第二层；hold-out 零结果与负对照刻画第一层边界。

### 1.2 化学试验田动机

精确 SMILES 匹配毫不容情，监督稀缺（本文 46/97），评测污染可伪装为泛化。更广的 RSI 文献中，「自我改进」强主张常依赖不受控协议漂移或污染评测。在声称泛化或持续自我改进之前，须确立：（1）干预在**固定协议**下导致可复现改进；（2）改进能迁移到**键级真正不相交**的数据。本文针对 **失败驱动数据策展** 回答二者。

### 1.3 研究问题（第三层操作化）

**RQ0（贯通三层）：** 在泄露受控的少样本反应产物预测中，何种闭环干预能产生可复现的**有界**改进，其边界在哪里？

**RQ1（数据策略）：** 失败驱动增广是否优于预算匹配的随机增广？

**RQ2（执行/调度）：** 递归调度类干预（硬回滚）或同池朴素扩容能否进一步提升？

**RQ3（第一层边界）：** 域内增益能否转移到与 train∪eval 反应键不相交的 hold-out？

**RQ4（评估诚信）：** 协议漂移与评测污染如何导致假阴性/假阳性？

### 1.4 范围与定位

本工作在 RSI 议程内研究 **有界数据中心自精炼**，明确定位为：

* **范围内：** 失败驱动策展的受控实证（第二层机制）
* **范围内：** 含泄露审计的协议保真（第三层纪律）
* **范围内：** 负结果与撤回的透明报告（第一层边界）
* **范围外：** 开放/持续 RSI 的验证
* **范围外：** 可靠跨划分化学泛化的演示
* **范围外：** 生产就绪系统
* **范围外：** 元层 improver 自我改写

### 1.5 贡献

1. **三层问题框架**（§1）：将 RSI 级问题收束为可证伪的数据中心化学闭环
2. **协议方法**（§3）：泄露受控划分、配方锁定与审计标准（RQ4）
3. **主效应**（§4）：A_fail ≫ A_rand（+66.60pp，N=5，RQ1）
4. **负对照**（§5）：M3 回滚、P2a 扩容、P1 LR decay 均失败（RQ2）
5. **Hold-out 零泛化**（§6）：干净外集上 0%（RQ3）
6. **科学诚信**（附录 B）：撤回污染外集虚假分数（RQ4）

## 2\. 相关工作

### 2.1 少样本化学反应预测

SMILES 格式的反应产物预测要求精确字符串匹配，使少样本设定尤为挑战。先前关于分子表示学习 [11, 12] 与神经反应预测 [13, 14] 的工作在较大数据集上取得进展，但精确匹配少样本预测在化学领域仍探索不足，具有高方差与易受评测污染的特性。计算机辅助合成规划 [15] 进一步凸显了分类式基准与本文精确 SMILES 设定之间的差距。

USPTO 等大规模反应语料催生了强劲的 seq2seq 与图基线——增广 NLP Transformer 在 USPTO-50K 上达到 top-5 ≈ 85% [17]，Graph2SMILES 将 Transformer 解码与置换不变图编码器结合，在同基准上 top-1 ≈ 55% [18]——但这些设定依赖数万级配对样本，与本文的少样本机制截然不同。近期化学 LLM（ChemLLM [16]、ChemDFM [19]）展示了领域定向预训练与指令微调在化学问答与反应任务上的收益，但其评测集中于多样本基准（如 ChemBench [16]），而非精确匹配少样本产物预测。逆合成综述 [20] 同样指出，多数 ML 方法依赖丰富配对数据，少样本产物预测仍属研究空白。

**与本工作的联系：** 精确匹配少样本预测的困难支持我们在固定预算下关注*如何*选择数据（失败定向 vs 随机），也有助于理解 0% hold-out 结果。

### 2.2 困难样本挖掘与失败驱动学习

超越机器学习启发式，更广的认识论立场主张：进步往往更多来自诊断失败，而非重复成功——错误约束了哪些理论仍可成立。主动学习 [5] 与课程学习 [6] 在计算上呼应此观点：决策边界附近或模型当前失败的样本提供不成比例的信息。近期关于 LLM 自我改进的工作 [9] 也呼应此主题，但通常针对更大规模设定。少样本设定下，随机增广稀释信号；失败定向选择把修正集中在预测器仍错之处。

**与本工作的联系：** RQ1 直接检验此假说：A_fail vs A_rand 在*名义*匹配预算下隔离选择策略——即「从错误中学习」是否优于「从更多同类经验中学习」。

### 2.3 数据中心 vs 算法中心方法

数据中心 AI 运动 [7, 8] 主张，在许多实际设定中，数据质量与选择（而非仅模型架构）是改进的主要杠杆。本工作将此扩展到少样本机制：仅 46 个训练样本时，在匹配预算下*策展哪些样本*比无差别堆量更重要。

**与本工作的联系：** RQ2 负对照（M3、P2a）证明无策展的朴素扩容无效或有害。

### 2.4 递归自我改进（RSI）与有界自精炼

RSI 文献 [1] 讨论经由自生成训练信号的开放能力增长。强主张至少需要：（1）固定协议下可复现改进；（2）超出训练分布的迁移；（3）评测诚信——后者在更广的迁移学习评估中亦被关注 [10]。我们的**第一层**继承该议程，但将主张类限制为 **有界自精炼**：可审计的域内增益 + 显式负边界。结果表明（1）在配方锁定下对失败驱动策展成立，（2）在键不相交 hold-out 上失败，（3）无反应键审计时易被违反——故本文**不**成立持续 RSI。

**与本工作的联系：** §1.1 三层栈将 RSI 级问题映射到数据中心化学闭环；实验检验机制与边界，而非断言开放 RSI。

## 3\. 问题设定与协议保真

### 3.1 任务定义

**任务：** 给定反应物 SMILES 与反应条件（类型、试剂、溶剂、温度、时间），预测主要产物 SMILES。

**评测：** 规范 SMILES 归一化后的精确字符串匹配。无部分得分。

**数据集划分（v9\_g1prime）：**

* 训练集：46 个反应（23 种类型，每类型 1–4 个样本）
* 评测集：97 个反应（21 种类型）
* ID 重叠：0
* 完整反应键重叠：0

### 3.2 协议保真措施

#### 3.2.1 配方锁定

我们在初始探索后冻结所有超参数，并报告配方哈希以保证可复现性：

| 组件 | 取值 |
| :--- | :--- |
| 基座模型 | Qwen2.5-7B [2] |
| 精度 | bfloat16（禁用 fp16——导致 NaN） |
| LoRA 秩 | r=16, α=32 [3] |
| LoRA dropout | 0.05 |
| 目标模块 | q\_proj, v\_proj, k\_proj, o\_proj, gate\_proj, up\_proj, down\_proj |
| 学习率 | 5e-5；按轮衰减 `0.85^(r-2)` + CosineAnnealing（η\_min/η\_max = 0.1） |
| 批量大小 | 1（40GB 显存约束；无梯度累积） |
| 训练轮次 | 7（每轮 3 epoch） |
| 增广 | A\_fail，K=1.0×；prompt 变体（condition/hint/format 切片） |
| **配方哈希** | `9e3788dd7a2eb89d66a1b403d5c5b7c425d583adf7c799c35b761b57fbf7f809` |

#### 3.2.2 泄露审计标准

在任何实验之前，我们验证：

1. **ID 重叠：** train/eval/external 之间无共享 ID
2. **产物重叠：** 检查共享产物 SMILES（若为不同反应则非泄露）
3. **完整反应键重叠：** 检查共享（反应物 → 产物）元组——**必须为 0**

#### 3.2.3 主要指标

* **峰值准确率（Peak）：** 训练轮次中的最大准确率
* **末轮准确率（Final）：** 最后一轮（第 7 轮）准确率
* **回撤（Drawdown）：** Peak − 峰后最低点（灾难性遗忘代理）
* **报告方式：** N=5 种子（41–45）的均值 ± 标准差

### 3.4 数据诚信：污染外集撤回

在外集评测期间，我们发现最初报告的「外集」（n=100）有 **82/100 个样本与 eval 集完整反应键重叠**。尽管 ID 不同，底层（反应物 → 产物）元组重复。

**采取的行动：**

* 撤回 63% 准确率主张
* 重建干净外集（n=31），与 train∪eval **反应键零重叠**
* 在干净集上重新运行所有外集评测

此事件强调 RQ4：评测污染可对泛化主张产生假阳性。

## 4\. 主结果：失败定向 ≫ 随机（RQ1）

### 4.1 实验设计

**假说：** 若信息瓶颈位于模型错误区域，则对失败案例的定向增广应优于匹配的随机增广。

**设定：**

* 模型：Qwen2.5-7B + LoRA（bf16）
* 种子：41, 42, 43, 44, 45
* 比较：A\_fail（失败定向）vs A\_rand（同池随机采样）
* 数据预算：跨条件*名义* K 匹配（轮内残差计数不平衡见附录 C.3）

### 4.2 结果

**表 1：In-Split 结果（N=5，均值 ± 样本标准差）**

| 方法 | 峰值准确率 | 末轮准确率 |
| :--- | :---: | :---: |
| **A\_fail（本文）** | **77.73% ± 2.79%** | **75.26% ± 5.41%** |
| A\_rand（基线） | 11.13% ± 0.46% | 9.90% ± 1.65% |
| **Δ** | **+66.60pp** | **+65.36pp** |

主结论以峰值准确率（预注册的峰值对照）为准；末轮 Δ 一并报告以示完整。A\_rand 全程约 \~10%，故大差距并非仅由「挑峰值」造成。

**表 2：逐种子明细**

| 种子 | A\_fail 峰值 | A\_rand 峰值 |
| :---: | :-------: | :-------: |
| 41 | 76.29% | 11.34% |
| 42 | 74.23% | 11.34% |
| 43 | 81.44%\* | 10.31% |
| 44 | 79.38% | 11.34% |
| 45 | 77.32% | 11.34% |

\*种子 43 为表现最佳种子，但 **非** 主要报告数字。

### 4.3 解读

1. **效应量：** +66.60pp 为大效应，且 **5/5 种子** 均为 A\_fail > A\_rand（与附录 C.1 中 1.5B G3 配对检验同向）
2. **机制：** 失败定向选择将学习信号集中于错误区域
3. **容量 vs 策略：** A\_rand@7B ≈ 11% 表明单靠容量不足；**策展哪些样本** 比无分化加量更关键
4. **可复现性：** A\_fail 峰值标准差较低（2.79pp），域内效应跨种子稳健

### 4.4 机制验证（1.5B 补充）

为确认 7B 效应反映与小规模相同的机制，我们在 Qwen2.5-1.5B 上进行平行实验（详见附录 C）：

* **G3：** A\_fail vs A\_rand 复现该模式（Δ = +13.0±4.5pp，5/5 种子一致）
* **M1：** 留一类型分析显示无 prompt 变体为增益之必要条件
* **M2：** 剂量-反应曲线显示 **选择策略** 主导 **数据量**（K=0.5×/1.0×/2.0× 下 Δ 一致）

**结论：** 7B 结果是同一数据中心机制的容量放大版本。

## 5\. 负对照：何者无效（RQ2）

### 5.1 M3：硬回滚

**假说：** 锁定到早期峰值检查点可防止灾难性遗忘并保持增益。

**结果：**

* 峰值准确率：相对无回滚基线 **−6.19pp**
* 行为：锁定到第 2 轮，阻止后续探索
* **解读：** 过早承诺到早期性能有害

### 5.2 P2a：朴素扩容

**假说：** 添加同池更多数据提升绝对性能。

**结果：**

* 典型在 **第 2 轮** 出现早期峰值，随后多轮 **单边下滑**（末轮大跌、回撤大）
* **解读：** 分布偏移增量（如产物 SMILES 显著更长）在朴素合并后损害后期表现——无分布控制的加量 ≠ 策展

### 5.3 P1：LR 衰减调整

**假说：** 调整学习率衰减（0.85 → 0.90）可稳定种子 45 的高回撤。

**结果：**

* 峰值准确率从 77.32% 降至 70.10%
* 未通过预注册稳化门禁（−2pp 阈值）
* **解读：** 局部超参数调整无法无风险地覆盖默认配方

**表 3：负对照总结**

| :--- | :--- | :--- | :--- |

**理论含义：** 这些负结果约束了「何种闭环算改进」的空间。具体而言，忽视分布偏移或过早承诺的干预失败。

## 7\. 讨论

### 7.1 回到三层问题与 RQ0

**认识论语汇。** 经验模式契合一条朴素却有力的主张：在科研与日常生活中，**从失败中吸取的教训在某种程度上比从成功中获取的经验更重要**。A\_fail 将该主张操作化为训练策略；A\_rand（以及朴素扩容）主要重复无分化经验，在精确匹配少样本化学上收益甚微。

**第一层（RSI 级）：** 递归更新*可以*产生可审计增益，但须协议保真；硬回滚未能控制回撤；跨划分迁移失败——标出清晰**边界**。

**第二层（机制）：** 起作用的杠杆是 **失败驱动数据策展**，而非无约束调度或朴素扩容。

**第三层 / RQ0：** 失败驱动策展带来大幅、可复现的 **域内** 增益（+66.60pp）。增益是 **有界的**：在精确 SMILES 下不迁移到键不相交 hold-out，因而**不**成立开放 RSI。换言之，**败中取法**在分布内很强，但并非通向开放自我改进的自动通行证。

### 7.2 与 RSI 的关系

**表 6：有界精炼 vs RSI**

| 标准 | RSI 主张 | 本工作 |
| :--- | :----: | :---: |
| 固定协议下可复现改进 | 需要 | 已证明（域内） |
| 向未见数据泛化 | 需要 | 未观测到 |
| 多任务/多域验证 | 需要 | 仅单任务 |
| 无评测污染 | 需要 | 已审计（含撤回） |

**定位：** 本工作证明 **有界数据中心精炼**，非开放 RSI。负 hold-out 结果是重要的边界条件。

### 7.3 局限

1. **数据规模：** 46 个训练样本，23 种反应类型——**较少样本**设定（few-shot），而非大规模监督
2. **Hold-out 规模：** n=31，18 种类型标签——样本小，置信区间宽
3. **单任务：** 仅反应产物预测；无跨任务验证
4. **LoRA 非全量微调：** 可能限制适应能力
5. **多种子外集评测：** 因强零结果而跳过
6. **类型名重叠：** Hold-out 中 14/18 类型与训练同名，使「未见类型」主张复杂化

### 7.4 评测诚信的教训

污染外集事件（§3.4）突出几个方法论教训：

1. **ID 级去重不足：** 完整反应键审计必要
2. **污染产生假阳性：** 污染集上 63% vs 干净集上 0%
3. **撤回必要：** 科学诚信要求更正记录
4. **预注册有帮助：** 审计标准应在评测前设定

### 7.5 对化学 LLM 评测的启示

我们建议未来关于闭环化学 LLM 改进的工作采用：

1. **键级泄露审计**（不仅 ID 去重）
2. **预注册评测协议**
3. **透明撤回政策**
4. **有界主张**（域内 vs 泛化）

***

## 8\. 结论

我们研究了失败驱动数据策展作为少样本反应产物预测中有界精炼机制。我们的发现：

1. **RQ1（域内效应）：** 失败定向增广大幅优于随机增广（+66.60pp，N=5，5/5 同向），表明在名义等预算下，**失败局部化选样**主导无分化加量。
2. **RQ2（负对照）：** 硬回滚、朴素扩容与 LR 衰减调整均未能提升（甚至损害）性能，约束「何种闭环算改进」。
3. **RQ3（泛化）：** 在反应键零重叠的干净 hold-out（n=31）上，基座与微调 LoRA 均为 0% exact-match——域内增益在本协议下**未观测到迁移**。
4. **RQ4（诚信）：** 评测污染可对泛化主张产生假阳性；键级审计与撤回政策至关重要。

### 8.1 有界自精炼作为中间主张类

**总体结论：** 在 RSI 研究议程内，我们以三层路径从「可验证递归改进」的领域问题，经数据中心化学闭环，落到可证伪 RQ。失败驱动策展带来大幅、可复现的 **域内** 增益，且保持 **有界**——既非跨划分泛化，亦非开放 RSI。我们提出，**有界数据中心自精炼**是通向更强 RSI 假说的严谨**中间主张类**。所谓「中间」，指下列四项须同时成立：

1. **作用域受限（可主张什么）。** 与开放 RSI（主张跨任务、跨分布的无界能力增长）不同，有界自精炼将主张限于：（a）固定任务；（b）固定训练/评测分布（本文为 v9 in-split）；（c）固定评测协议（精确 SMILES；锁定配方）。这不是弱点，而是方法学前提：把机制（失败驱动策展）与混淆因素（协议漂移、评测污染）隔开。
2. **可审计的进展单元（必须量什么）。** 在锁定配方下，每次运行输出预注册的指标面——峰值、末轮、回撤，以及多种子均值±SD——以便第三方复现核实。我们**不**主张准确率每一轮单调上升（轨迹可振荡；把早期峰值冻住的硬回滚有害）。可审计性针对**协议定义的可复现对照**（如 A\_fail vs A\_rand），而非「逐轮必然爬升」。开放 RSI 修辞常在未固定评测面时把「改进」混同为模糊的「能力增长」。
3. **显式的负边界（必须否定什么）。** 严谨中间主张类须同等有力地说明*何处失效*。Hold-out 零结果（§6）与负对照（§5）刻画失效区：域内增益不会自动迁移至键不相交数据；并非一切闭环干预都算改进（硬回滚；朴素并入偏移数据）。这些边界与 +66.60pp 正效应同样用于校准未来 RSI 预期。
4. **阶梯，而非终点（仍开放什么）。** 有界自精炼并非 RSI 终态。更强假说仍须在**同一审计纪律**下证明：（a）跨任务迁移（如反应预测→逆合成）；（b）在**干净** hold-out 上的分布偏移/新类鲁棒性；（c）**元层**改进（策展*策略本身*跨轮改善）。本文中失败→增广规则仍为**人设计**，不声称 improver 自我改写。贡献是方法学模板——固定协议、可审计对照、显式否定——更强主张仍须满足。

**总结：** 我们既不声称「已实现 RSI」，也不声称「RSI 不可能」，而是给出介于朴素自我改进断言与开放 RSI 之间的、可证伪主张类。未来可在保持键级审计与预注册指标的前提下扩展任务或引入元学习，使改进主张可验证而非仅为愿景。

**未来工作：** 迈向更强的跨划分/跨类型表现，可能同时需要（i）**更大容量的基座模型**（在锁定协议下对照，而非无对照冲分），与（ii）**更多高质量、分布受控且键级无泄露的数据**（坚持失败驱动策展，避免重复 P2a 式盲目堆量）。亦可探索显式域适应或元学习；但任何更强主张仍须在真正独立的 hold-out 上用预注册协议验证。
