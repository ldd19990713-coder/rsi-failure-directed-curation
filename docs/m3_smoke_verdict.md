## 2. 冒烟结果核对

| 指标 | A_rollback | A_fail 对照 | Δ |
| :--- | ---: | ---: | ---: |
| Peak | **15.46% @ R2** | 21.65% @ R5 | **−6.19pp** |
| Final | 15.46% | 20.62% | −5.16pp |
| Drawdown | 0.00% | ~1.03% | 形式下降 |
| 回滚次数 | 5（R3–R7） | — | — |

- Peak 掉幅 **≫ 2pp** → 按协议 **策略失败**。  
- Drawdown=0 是「锁死在 early best」的假稳健，**不是**成功标准（成功要求 final↑ 且 peak 不大崩）。

### 机制（同意冒烟解读）

```
R2 达 best 15.46% → 存盘
R3–R7: eval < best → 硬回滚到 R2 权重
→ 后续轮无法积累越过 R2 的轨迹 → peak/final 卡死在 15.46%
```

硬回滚把「拒绝变差」做成了「禁止探索越过早期局部峰」。对照无回滚可在 R5 到 21.65%，说明该种子上**后期仍有可学增益**，被回滚切断。

## 3. 对研究叙事的含义

| 层级 | 更新 |
| :--- | :--- |
| 数据中心主线（失败选样） | **不变** — G3/M1/M2 仍成立 |
| 「多轮 + 采纳/回滚 = 稳健自精炼」 | **本协议硬 τ=0 不支持** |
| G4 递归边际 | **一致** — 调度层小改不救、硬回滚还伤 peak |
| 持续 RSI | **仍禁止宣称** |

**可写负结果**:  
> 在 A_fail×K=1.0×、seed41 上，轮末若低于历史 best 即硬回滚权重，导致峰锁在 R2（15.46%），相对无回滚对照 peak −6.19pp（超过 −2pp 失败线）。表明该硬回滚阻碍后续学习，不作为默认稳健化手段。

## 4. 为何不继续全批量 / 不立刻改策略批量

| 做法 | 问题 |
| :--- | :--- |
| 再跑 41–45 硬回滚 | 同一规则下「锁 early peak」高度可迁移；边际信息低，烧 ~7h |
| 冒烟后立刻软回滚/限次全网格 | 未冻结新成功标准就开跑 → 协议漂移风险；且与「抬绝对水平」抢 GPU |

**若未来做 M3′（低优先，不挡 P2）**，须先书面冻结其一，且 **单种子冒烟过线再批量**：

| 变体 | 要点 | 过线草案 |
| :--- | :--- | :--- |
| 限次回滚 | 最多回滚 R 次或仅 R≥r0 后启用 | peak≥对照−2pp 且 final≥对照 |
| 容忍带 | 仅当 drop > τ（如 1/97 或 2pp）才回滚 | 同上 |
| 软回滚 | EMA / 部分权重混合，非整模重置 | 同上 + drawdown 改善 |

默认：**不排进现行关键路径**。
