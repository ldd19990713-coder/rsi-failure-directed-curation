## 1. 总判决

| 议题 | 判决 | 信心 |
| :--- | :--- | :---: |
| 是否存在「必要」变体类型（Δ≤−3pp 且 ≥2/3 同向） | **否 — M1 阴性** | 🟢 |
| synonym / context LOO | **无效实验**（管道 `[:k]` 从未调用） | 🟢 |
| 「措辞多样性」是否 A_fail 主因 | **现证据不支持**；更指向**失败样本选择** | 🟡 |

**一句话**: 在现行 canonical 切片下，**没有一类 prompt 变体是 A_fail 增益的必要条件**；真正该追的是「增广谁 / 增广多少」，不是「用哪句 prompt」。

## 2. 结果核对

### 2.1 与协议标准对齐 — 同意报告

| 变体 | 报告判定 | 本裁决 |
| :--- | :--- | :--- |
| condition | INCONCLUSIVE | **同意**（跨种子 −7.2 / +13.4 / +2.1） |
| hint | HARMFUL（移除↑） | **同意「非必需」**；「有害」仅作描述，**勿升格为因果定论**（N=3、2/3） |
| format | HARMFUL（移除↑） | 同上 |
| synonym / context | NEUTRAL（未使用） | **同意** — 标为 **管道未触及**，禁止写进「变体无用」叙事 |

### 2.2 结构性发现 — 接受并写入冻结说明

`num_variants`: easy/hard=2、medium=3，且 `active_types[:k]` → 实际只用 **condition / hint /（medium）format**。  
→ 所谓「5 类 Full5」名不副实；对外应称 **「现行切片下的有效 3 类」**。

### 2.3 必须澄清：M1 Full5 ≠ Phase3 G3 A_fail（同种子）

| Seed | Phase3 A_fail peak | M1 Full5 peak | 差 |
| :---: | ---: | ---: | ---: |
| 41 | 19.59% | **22.68%** | +3.09pp |
| 42 | 14.43% | **19.59%** | +5.16pp |
| 43 | 23.71% | **15.46%** | −8.25pp |

Recipe hash 声称一致，但 **逐种子峰值不复现**。可能原因：`m1_leave_one_out.py` 与 `train_canonical`/`g3_g4` 仍有实现差；或非完全确定性（RNG/数据序）。

**要求（M2 开跑前完成，约 0.5–1 天，可与 M2 脚本开发并行）**:

1. 对照 `m1_leave_one_out.py` vs `g3_g4_canonical.py` A_fail 路径的 diff（aug、LR、batch、seed、generator）。  
2. 文档写明：M1 的 Δ 是 **相对本脚本 Full5**，**不得**与 Phase3 绝对峰值混表。  
3. 若 diff 非空 → 修到与 canonical A_fail 一致后，**不必重跑全部 LOO**；以质性结论（无必要类 + 切片结构）为准，定量 Δ 标「探索级」。

## 3. 对研究叙事的更新

| 层级 | 更新 |
| :--- | :--- |
| 数据中心主线 | **加强**：G3「选失败样本」仍是主增益；M1 显示 **prompt 类型可替换** |
| 「5 类精心设计变体」 | **降级**：现行协议下仅 3 类生效；且无一类必要 |
| 多样性 vs 体量 | **优先假说**：volume / 失败定向 ≫ 措辞多样性 → **由 M2 正式检验** |
| 递归 / RSI | **不变**：仍禁止「持续 RSI 已验证」 |

**可用主张（谨慎）**:  
> 在 V5 canonical 失败驱动设置下，对实际使用的 prompt 变体做 leave-one-out（N=3）未发现任一类满足必要性标准；synonym/context 因 `num_variants` 切片未被调用。结果与「增益主要来自失败样本选择而非特定措辞」相容，待等量曲线（M2）进一步检验。

## 4. 下一步实验指导（排序）

### P0 — 开 M2 前（短）

| # | 行动 | 产出 |
| :---: | :--- | :--- |
| 0 | 脚本 diff：M1 runner vs Phase3 A_fail | `docs/m1_vs_phase3_afail_diff.md` |

### P1 — 主实验 **M2 等量增广曲线**（最高优先）

**问题**: A_fail≫A_rand 是因为 **定向选失败**，还是因为 **有效增广条数**？

| 项 | 规定 |
| :--- | :--- |
| 臂 | A_fail vs A_rand，**同 K** |
| K | `{0.5×, 1×, 2×}`，1×=现行 G3 每轮增广条数（先数清楚写进 tag） |
| 种子 | 41–43；若 Δ 稳定再 41–45 |
| 变体 | **冻结为现行切片**（勿同时改 num_variants=5） |
| 入口 | 与 Phase3 A_fail **同一 train 路径**（修完 diff 后） |
| 解读 | 全 K 上 A_fail>A_rand → 定向稳健；仅大 K 拉开 → 量主导；小 K 也拉开 → 选样主导 |

### P2 — 轻量 M1 收尾（可选，不挡 M2）

| 代号 | 内容 | 何时做 |
| :--- | :--- | :--- |
| **M1b** | condition-only vs hint-only vs format-only（**单类 × 等条数**） | M2 1× 点跑完后；seeds 41–43 |
| **M1c** | 仅扩 **condition** drop 到 seeds 44–45 | 仅当仍想估 condition 效应量；**不要**重跑 synonym/context |
| **M1d** | `num_variants` 提到真正用满 5 类后再 LOO | **低优先**；属改协议，需新 hash 分支，勿与 M2 混 |

### P3 — M3 采纳/回滚

仍值得做（A_fail 回撤大），但 **排在 M2 最小曲线之后**（至少完成 K=1× 与 2×）。

### 明确不要做

| 禁止 | 原因 |
| :--- | :--- |
| 把 hint/format「有害」写成定论并改默认配方刷分 | N=3、不稳定 |
| 宣称「5 类变体均无用」 | 2 类从未调用 |
| 未修 Full5↔Phase3 不一致就扩 N=5 全 LOO | 浪费 GPU、归因脏 |
| 同时开 M2 + 改 num_variants=5 + 扩 train | 混因 |
| 因 M1 阴性否定 G3 | G3 检验的是**样本选择**，M1 检验的是**措辞类型** |
