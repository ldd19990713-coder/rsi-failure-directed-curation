## 1. 总判决

| 议题 | 判决 | 信心 |
| :--- | :--- | :---: |
| 全 K 上 A_fail > A_rand？ | **是（9/9）** — 定向效应稳健 | 🟢 |
| 增益是否「只靠加量」？ | **否** — A_rand 加到 2× 仍 ~5%；A_fail 剂量非单调 | 🟢 |
| 小 K 是否仍拉开？ | **是** — K=0.5× 时 Δ 最大（≈+20pp） | 🟢 |
| 协议解读（选样 vs 体量） | **选样（失败定向）为主驱动** | 🟢 |
| 严格逐轮等量？ | **未完全满足**（A_rand 总条数偏高）— 不推翻方向，削弱「等量」措辞 | 🟡 |
| M2 可否关闭？ | **可关闭（质性）**；可选 M2b 严格配对加固 | 🟢 |
| 下一步主实验 | **M3 采纳/回滚**；并行考虑 **扩 train≥200** | 🟢 |

**一句话**: 在 0.5×–2× 剂量上，**失败定向全面且稳定优于随机增广**；加大随机量救不了 A_rand，加大失败量也不保证单调升分 → 机制核心是 **选哪些样本**，不是 **堆多少条 / 哪句 prompt**（衔接 M1）。

## 2. 协议对照解读

协议预设：

| 模式 | 含义 | M2 结果 |
| :--- | :--- | :--- |
| 全 K 上 A_fail>A_rand | 定向稳健 | **命中** |

## 3. 局限与必须写入的 caveat

1. **等量不严**: 同 seed、同 K 下 A_rand 累计 aug 常多于 A_fail；对外宜写「近似等预算 / 名义 K 倍」，或补 **M2b**（每轮将 A_rand 子采样到与当轮 A_fail `aug_count` 完全相等）。  
2. **N=3**: 方向极稳；效应量 SD 大（尤其 K=2×、K=0.5×），投稿可扩 seeds 44–45 仅做 K=1.0×。  
3. **分析脚本失败**: 已用 CSV 重算；修复 `analyze_m2_dose.py` 的 tag 解析（勿再切到 `'ai'`）。  
4. **绝对峰值**: seed43@K0.5 达 34%、seed41@K2 达 33% — 单点高，**勿**升格为新基线；官方对照仍用 Phase3 / K=1.0 均值叙事。

## 4. 对研究叙事的更新

| 证据链 | 状态 |
| :--- | :--- |
| G3：失败样本 > 随机样本 | **支持**（+13pp） |
| M1：特定 prompt 类型非必要 | **支持**（LOO 阴性） |
| M2：剂量上定向仍全面胜出；量救不了随机 | **支持** |
| G4 / 递归调度 | **仍边际** |
| 「持续 RSI」 | **仍禁止** |

**主张模板（可用）**:  
> 在 V5 canonical 下，失败驱动增广相对名义同倍随机增广在 K∈{0.5,1,2}× 上全面更优（9/9，K=1× 时 Δ≈+14pp）；随机臂加大剂量无明显收益，失败臂剂量–峰值非单调。结合变体 leave-one-out 阴性，结果支持「增益主要来自失败样本选择（数据策展）」而非措辞多样性或单纯增广体量，亦不支持将递归调度表述为充分的持续自我改进机制。

### P1 — 主实验 **M3 采纳/回滚**（最高优先新跑）

**动机**: A_fail 仍常有大 drawdown（本包多点 final≪peak；Phase3 mean DD≈12.6%）；K 增大不保证更稳。

| 项 | 规定 |
| :--- | :--- |
| 数据策略 | **冻结 A_fail + K=1.0×**（默认作战点） |
| 因子 | 轮末若 eval 低于历史 best → **回滚权重**（先 τ=0） |
| 对照 | 无回滚 A_fail（可复用 M2 K1.0 或 Phase3） |
| 种子 | 41–45 |
| 成功 | drawdown ↓、final ↑；peak 掉 >2pp 则策略失败 |
| 禁止 | 同时改 K / 变体 / 扩模 |
