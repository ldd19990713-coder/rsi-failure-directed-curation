## 3. 能否写论文？

### 可以写什么（建议定位）

**有界、数据中心的失败驱动自精炼（few-shot 化学 SMILES）实证 + 机制消融**，例如：

- 协议保真与漂移（P1 伪阴性 / D1–D3）  
- 失败定向 ≫ 随机 / ≫ 措辞类型（G3、M1、M2）  
- 硬回滚与朴素扩容负结果（M3、P2a）  
- 容量跃迁：7B+LoRA 抬天花板，且定向仍必要（P2b）  
- 外持有：adapter 后 63% vs 基座 1%，in-split 落差 ~18pp（P2′）

### 现在还不能写什么

| 禁止主张 | 原因 |
| :--- | :--- |
| 「RSI / 持续自我改进已验证」 | 证据是策展+FT，非开放自我改进 |
| 「已具备可靠跨域泛化」 | 单 seed 检查点；外集仍是同任务同提示格式；未做严格 OOD 新类型 |
| 「18pp 落差已证明由类型偏移导致」 | 相关 ≠ 因果 |
| 「可部署生产系统」 | 数据面与评测面仍窄 |

### 成文前 **建议补齐**（按是否阻塞投稿）

| # | 工作 | 阻塞初稿？ |
| :---: | :--- | :---: |
